# 润泽说 道可道之论语

《论语》的**通释读本**：一章一课，一课两页——少儿页可念，成人页可考。底本朱熹《论语集注》，全书依朱子本分章，共 **四百九十八章**，按篇连载。

> 这本书只做一件事：**把原文摆回它自己的时代，让它说自己的话；义理另开一节，标清是谁的引申。**
> 凡解读须指回原文的哪个字、哪一句；指不回去的，写进「存疑」，不写成定论。

## 一、两条总纲

**一阴一阳之谓道。** 移到学上就是学与习：**学是受**（听、读、接过来，向内收，阴），**习是发**（练、做、讲出去，向外放，阳）。只学不习，是替别人保管知识；只习不学，是自己摸黑走路。「学而时习之」六字藏着这一整条。

**君子不器：可器而不着于器。** 器是通道，不是身份。君子能作器、能用器，而不把自己钉成一件器具；能通达四端，亦能退藏于密。通道——学问是流得过去的东西，堵则满，通则不执。

## 二、体例：一课两页

| 页 | 有什么 |
|---|---|
| **少儿页** | 字义小课堂、一句话讲清、共读、生活里的一天、三个小问题、成长小启示、家长栏（勘俗见／现代对照／常变主线／教与学二分／时代落点／融西／可做一件） |
| **成人页** | 连读、字义句读、时代背景、章旨、朱子注、分寸、反面、张力、脉络、跨典、存疑、双卡、阴阳五蕴；后附典故图与读图、义理图、附论 |

- **典故图**由作者供图，助手只写提示词、不擅自生图。
- **义理图**手写 SVG，页面内嵌为唯一源，另导出独立文件随仓库留存（`assets/`）。
- **存疑**：被否定的解读不销毁，撤出正文另标「存疑」，不写成定论。

## 四、仓库结构

```
book/     母本（md，唯一内容源）
docs/     站点（GitHub Pages，main:/docs）
  index.html     入口：卷首语、目录、体例、五步读法、同系列
  book.html      卷首：封面、扉页、前言十节、六课目录
  ke/*.html      各课阅读版（单文件自包含，含内嵌 SVG 与典故图）
scripts/
  build_book_md.py   各课 md → 母本
  build_site.py      母本与阅读版 → docs 站点
  daokedao_book.py   系列共用排版件（cover / frontis / fig_*）
  svg_sync.py        页面内嵌 SVG ↔ assets/ 文件互校
assets/   义理图 SVG 与典故图 webp
```

改内容只改 `book/` 与各课源件，然后重建，不要直接手改 `docs/`。

## 五、构建
