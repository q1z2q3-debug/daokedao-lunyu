雍
一首诗的名字。——《雍》是天子宗庙祭完撤祭品时唱的乐歌。
彻
撤下、收去。——「彻」通「撤」；祭礼完毕，把祭品礼器撤下来。
辟
君长、诸侯。——「辟公」就是助祭的诸侯；这里的辟，不要写成偏僻的「僻」。
穆
庄重盛美。——「穆穆」是天子仪容庄敬盛美的样子；不要写错成「繆」。
一句话讲清
三家大夫在家庙撤祭，也唱天子祭祖的歌；孔子反问：诗里写的是诸侯助祭、天子主祭，在你们家堂上去，哪一点用得上？——（八佾 3.2）

孔子说：三家大夫撤祭的时候，用了天子撤祭才唱的《雍》。——他引诗两句反问：诗里是诸侯来助祭、天子穆穆主祭；这样的场景，在三家的堂上，取它哪一点？

一句话：什么场合，用什么乐；场合对不上，排场再大也不对。

共读

第一层，先知道什么是「雍彻」。——祭礼做完，撤下祭品礼器，是彻；撤的时候唱什么歌，有等级。——《雍》是天子宗庙撤祭唱的歌。

第二层，再看诗里有谁。——「相维辟公」：诸侯来助祭；「天子穆穆」：天子主祭，仪容庄盛。——这首诗写的，是天子诸侯在一起的场面。

第三层，对一对位置。——三家是大夫；他们堂上主祭的是大夫，帮忙的是家臣。——诗里的人，堂上一个也对不上，所以孔子问：这诗在你们堂上去，取什么？

一句话说透：——乐是同一套乐，场合与位置对不上，就不能用。
生活里的一天

一　场合不对的称呼。——班里集会，席位是按身份和安排排的；坐到不属于自己的位置上，哪怕坐得端正，也是越位。

二　借来的仪式。——颁奖台、主席台是特定场合用的；把它搬回自家客厅当普通座位，仪式的意思就变了。

三　大家都这样就对吗。——几件事别人都跟着做，不代表就该做；俗成不是道理，还要看分际对不对。

三个场景是一件事：——场合有场合的位置，位置不能借，也不能抢。
三个小问题

一　唱歌这件事本身有错吗？——曲调没有错；错在场合与身份。——同一首歌，放在该放的场合是礼，放错了场合是僭。

二　心诚还不够吗？——诚要落在礼的分上。——心里再敬，越过了自己的位置，仍然不算合礼。

三　「三家」是谁？——通行说法是鲁国三桓：仲孙、叔孙、季孙三家大夫。

成长小启示
不属于自己的场合与位置，不去借、不去占。
礼乐随身份场景而定，不是看排场大不大。
大家都做的事，也要先问一句：该不该我做。
家长栏
语
陪读：——把本章讲成「场合与位置有分际」，不要讲成「音乐有阶级、不许唱好歌」。
用
日常场景：——看孩子在群体中是否占用不属于自己的位置、借用不属于自己的仪式；就事论事，不贴标签。
过
常踩的：——把「从众」当成理据：别人都这样，所以我也可以。——俗成不是标准，分际才是。
教与学
一法：——问孩子「这件事在什么场合」「你在其中是什么位置」——把场合与身份分开再合起来看。
时
时代特点：——仪式与头衔常被借用、升格；本章提醒：场合有其本分，借用的排场不等于资格。
融
跨学科：——古礼之乐与等级场景，可参《礼记》《周礼》相关篇目；诗的场景与人物，可参《诗经·周颂·雝》。
一
一句话：——教他做一个守场合、知位置的人。
成人页

三家者以雍彻

八佾 3.2　上论·八佾　底本：朱熹《论语集注》
三家者以雍彻。子曰：「相维辟公，天子穆穆，奚取于三家之堂？」
零　连读：从「僭数」到「僭位」

3.1 孔子谓季氏：「八佾舞于庭，是可忍也，孰不可忍也？」——季氏用天子之舞，僭的是佾之人数，是可数之量。

本章接在其后，再出一案：三家者以雍彻。——三家大夫在家庙撤祭，也唱天子宗庙撤祭所歌的《雍》。——僭的不是数量，是场景之位：诗里写的是谁在场、谁主祭，这一场景里没有大夫的位置。

《八佾》开篇两章，合看是「僭礼」两案：3.1 僭数，本章僭位。——数可点，位不可混；乐不是一段孤立的曲调，乐连着礼的场景与身份。

孔子引《雍》诗两句反问，不是嫌乐声不好，是指出场景对不上。——诗中无三家之位，于三家之堂何所取。

本章在《八佾》里的位置，是僭礼的第二案：僭乐即僭场景。——3.1 怒其数，本章诘其位；数乱在多少，位乱在归属。

句读是两停。——上停「三家者以雍彻」，摆出所行之事；下停「子曰：『相维辟公，天子穆穆』，奚取于三家之堂？」引诗反问，下断语。

读法上一处要紧：「奚取于」不是批评乐声，是追问场景。——诗里写诸侯助祭、天子主祭；三家之堂上，主祭的是大夫，助祭的是家臣——诗中的在场者一个也对不上，故曰无所取。

二　专题一　「雍彻」：撤祭之乐与天子之礼

本章先辨这桩乐事的本分。

古人祭毕，撤去祭品与礼器，谓之彻（撤）。——撤祭之时，依等级歌相应的乐：《雍》是《周颂·雝》，《毛诗序》谓「雝，禘大祖也」，《周礼·大司乐》「及彻，帅学士而歌彻」——天子宗庙撤祭，歌《雍》以彻。

三家为鲁大夫，家庙撤祭本有家臣之乐；以《雍》彻，是把天子宗庙的乐歌搬到自家堂上。

马融《集解》大意：《雍》，《周颂·雝》篇名，天子祭毕彻而去，歌《雍》以彻。朱子《集注》：「雍，《周颂·雝》之篇。彻，祭毕而彻俎也。」——注家语与孔子原话须分清：「三家者以雍彻」是孔子所举之事，「奚取于三家之堂」才是孔子所断。

这里要辨一层：本章所戒的不是用乐本身，是越等级而用乐。——乐有乐的本分，礼有礼的场景；撤祭之乐随祭者之位而定，位不同，乐不同。

反方须立：音乐只是声音，曲调何分天子大夫？——本课判：在孔子的礼中，乐不是纯声音。乐是礼的一部分，连着谁在场、谁主祭；曲调可同，场景不可移。

三　专题二　诗的场景：谁在场，谁主祭

孔子不直斥「僭」，而是引《雍》诗两句反问：「相维辟公，天子穆穆。」

《雝》全诗写禘祭太祖之盛：「有来雝雝，至止肃肃。相维辟公，天子穆穆。」——相，助也；辟公，诸侯；穆穆，天子仪容之盛美。诗中场景是：诸侯辟公前来助祭，天子穆穆然主祭于上。

《礼记·曲礼下》「天子穆穆，诸侯皇皇，大夫济济，士跄跄」——穆穆本是天子仪容之文。——诗以穆穆状天子，正见这一场景所属。

孔子的质问落在「奚取于三家之堂」：诗里有谁？有助祭的诸侯，有主祭的天子。——三家之堂上有谁？有大夫，有家臣。诗中的在场者，堂上一个也对不上；诗中既无大夫之位，这诗于三家之堂，取它哪一点？

故本章的核心不是音量、曲调、排场，是场景与在场者。——礼乐的正当性来自「谁在场、谁主祭」，而非曲调本身。同一套乐，放在天子宗庙是礼，搬到大夫家庙是僭；不是乐变了，是位变了。

四　专题三　僭乐即僭场景：与 3.1 合观

3.1 季氏八佾舞于庭，僭的是佾数：八佾为天子之舞，季氏用之，可数其人数。

本章三家以雍彻，僭的是场景：《雍》诗所写诸侯助祭、天子主祭之场，三家堂上并无此场。

两案合观，僭礼有两种形态：一僭数（可数之量），一僭位（场景之位）。——数乱在多少，位乱在归属。3.1 问「是可忍也，孰不可忍也」，本章问「奚取于三家之堂」：一怒其数，一诘其位。

这里要辨一层：本章不是 3.1 的重复课。——3.1 重在舞之人数，本章重在诗之场景与在场者。读本章须盯住「相维辟公，天子穆穆」两句：孔子把诗的场景摆出来，让三家自己对——对不上，便无所取。

五　反向：三种误读

三种误读，都在把本章的「礼」推过头或推干净。

一，乐无阶级论。——以为音乐只是音乐，曲调无分天子大夫，谁唱都一样。——正解：在孔子的礼中，乐是礼的一部分；乐随场景与身份而定，场景一移，乐即成僭。所争不在声音，在归属。

二，诚意论。——以为心诚则礼成，用什么乐是形式末节，心到了就不算僭。——正解：诚要落在礼的分上。3.12「祭如在，祭神如神在」是尽礼之诚；越分而用乐，心思不在敬，在僭。心再诚，分乱了仍是僭。

三，从众论。——以为三家皆然，俗成已久，不必独责三家。——正解：俗成不是理据。众人皆僭，僭仍是僭；本章所断在礼之当否，不在众寡。

一句话收：——本章戒在越分用乐：乐可同，位不可移。
六　章旨

一句。三家大夫家庙撤祭，歌天子撤祭之《雍》；孔子引诗反问：诗中诸侯助祭、天子主祭，这场景于三家之堂，取它哪一点？

一反。这不是论乐声好坏，也不是排抑大夫；所戒在越分用乐，僭在场景之位。

一辨。「彻」是撤去祭品，不是税法之彻；「辟公」之辟训君，与通「避」之辟、便辟之辟义别；「穆穆」是天子仪容，勿误作「繆」。

一证。七个数：「雍」全书六见，本章一见；「徹（彻）」三见，本章一见；「辟」十见，本章一见；「穆」二见，皆本章；「堂」五见，本章一见；「奚」十一见，本章一见；「三家」两见，皆本章。——「天子穆穆」「相维辟公」「辟公」全书各一见，皆本章。详见附论一至五。

本章在《八佾》的位置，是僭礼的第二案。——僭数之外又僭位；礼定其分，谁在场、谁主祭，乐便属谁。
七　存疑五条
01
《雍》是否确为天子撤祭所歌。《周礼·大司乐》「及彻，帅学士而歌彻」、《毛诗序》「雝，禘大祖也」可相互证；具体以《雍》为撤祭之歌，定自汉魏注说（马融、郑玄、朱子），《论语》经文内证仅此所引两句。本课从注说，两存。
02
三家指哪三家。通说鲁三桓：仲孙、叔孙、季孙；旧说或有歧解。本课从通说，行文标注「通说」。
03
「彻」字两义。本章通「撤」，撤去祭品；12.9「盍彻乎」「如之何其彻也」之「彻」为税法，什一而税曰彻。形近字「徹／撤」，归简作「彻」，两义不可混。
04
「辟公」之辟训君（诸侯），与通「避」之辟（辟世、辟人）、便辟之辟、「师也辟」之辟义别；「僻」为另一字，形近易淆。读旧本须先辨上下文。
05
本章与 3.1 是否重复。本课判互补：3.1 僭数（八佾之量），本章僭位（场景之位）；一在多少，一在归属。重复一路并存不废。

九　跨典六条
一
《论语》3.1「八佾舞于庭，是可忍也，孰不可忍也？」——同篇首章僭数；本章僭位，两案合观为「僭礼」两案。
二
《诗经·周颂·雝》「有来雝雝，至止肃肃。相维辟公，天子穆穆。」——全诗禘祭太祖，诸侯助祭、天子主祭；本章直引其中两句。
三
《礼记·曲礼下》「天子穆穆，诸侯皇皇，大夫济济，士跄跄。」——穆穆本是天子仪容之文；诗以穆穆状天子，正见场景所属。
四
《论语》3.12「祭如在，祭神如神在。吾不与祭，如不祭。」——祭之诚敬在礼之在场；本章从资格与场景立限。
五
《论语》16.3「禄之去公室五世矣，政逮于大夫四世矣，故夫三桓之子孙微矣。」——三桓执鲁政之源流；三家即此公族。
六
《论语》11.15「由也升堂矣，未入于室也。」——堂室之喻；本章「堂」指家庙之堂，与升堂入室可互参。

趋而辟之 / 辟人 / 辟世——通「避」，三见。

友便辟——便辟，逢迎之态。一见。

本章「辟公」之辟，唯取「君」义；与避、便辟、偏激诸义别。——「僻」为另一字，勿混。

附论四　「穆」二见、「堂」五见

底本全书 grep「穆」，凡二见；皆本章「天子穆穆」叠用。「穆穆」全书仅此一见。

底本全书 grep「堂」，凡五见；本章一见。

堂3.2
三家之堂——本章一见；三家家庙之堂。
堂10.3
摄齐升堂——君召摈相，趋进之礼。
堂11.15
由也升堂矣——堂室之喻，入室未也。
堂19.16
堂堂乎张也——叠字形容，一章两见。

「堂」在全书或指庙堂阶上之堂，或为叠字形容；本章「三家之堂」即三家家庙之堂。

附论五　「奚」十一见、「三家」两见

底本全书 grep「奚」，凡十一见；本章一见。

奚2.21
子奚不为政 / 奚其为为政——一章两见；疑问词，何。
奚3.2
奚取于三家之堂——本章一见；于其中取什么。
奚7.19 / 11.15
女奚不曰 / 奚为于丘之门——各一见。
奚13.3 / 13.5
奚先 / 奚其正 / 亦奚以为——三见；问政与诵诗之用。
奚14.19 / 14.38
奚而不丧 / 奚其丧 / 奚自——三见。

「奚」全书皆疑问词：何、什么、怎么。本章「奚取于」即「于其中取什么」。

底本全书 grep「三家」，凡两见；皆本章：「三家者以雍彻」「三家之堂」。——「天子穆穆」「相维辟公」「辟公」全书各一见，皆本章。
