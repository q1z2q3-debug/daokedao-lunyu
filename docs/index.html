卷首语为什么这样读

注了两千年的书，最容易被注遮住。这一部先做一件事：把原文摆回它自己的时代，让它说自己的话；义理另开一节，标清是谁的引申。

贯穿全书一条总纲：一阴一阳之谓道——学是受（阴、向内收），习是发（阳、向外放）。只学不习，是替别人保管知识；只习不学，是自己摸黑走路。

所以每一课都问一句：这章说的是哪件事、哪个字？说不出，就退入存疑，不写成定论。
