卷首语为什么这样读

注了两千年的书，最容易被注遮住。这一部先做一件事：把原文摆回它自己的时代，让它说自己的话；义理另开一节，标清是谁的引申。

贯穿全书一条总纲：一阴一阳之谓道——学是受（阴、向内收），习是发（阳、向外放）。只学不习，是替别人保管知识；只习不学，是自己摸黑走路。

所以每一课都问一句：这章说的是哪件事、哪个字？说不出，就退入存疑，不写成定论。

成人页
连读、字义句读、时代背景、章旨、朱子注、分寸、反面、张力、脉络、跨典、存疑、双卡、阴阳五蕴；后附典故图与读图、义理图、附论。每节先一句断语，再出证据。
图
典故图由作者供图，助手只写提示词、不擅自生图；义理图手写 SVG，页面内嵌为唯一源，导出独立文件随仓库留存。
存疑
被否定的解读不销毁：撤出正文，另存并标「存疑」，不写成定论。
